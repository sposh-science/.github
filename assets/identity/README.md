# SPOSH Visual Identity

Official visual identity resources for **SPOSH — Society for Promotion of Open Science Hardware**.

## The Mark

The SPOSH mark combines an **open hexagonal form** with a simple network of connected nodes.

The **open hexagon** represents openness, open science, and open hardware. The connected nodes represent collaboration, knowledge sharing, and participation in a wider open-science-hardware community.

The **small teal node** represents SPOSH as a local node connected to a broader network — small in scale, but actively contributing, sharing, and growing through the global open science hardware movement.

The intentionally open structure reflects the idea that knowledge, tools, and participation should remain accessible rather than enclosed.

## Colours

| Colour | Hex | Role |
|---|---|---|
| Deep Navy | `#10235F` | Primary structure and SPOSH wordmark |
| Bright Teal | `#00B8B0` | Active network nodes and accent |
| Warm Neutral | `#969383` | Intermediate network connection |
| Dark Slate | `#58677A` | Secondary structure and supporting text |

The primary logo uses flat colours without gradients.

## Typography

The SPOSH visual identity uses **Rajdhani**, an openly licensed typeface.

- **SPOSH wordmark:** Rajdhani Bold
- **Expanded name:** Rajdhani SemiBold, uppercase

The expanded name is presented as:

> SOCIETY FOR PROMOTION OF  
> OPEN SCIENCE HARDWARE

Public distribution SVGs use outlined text where appropriate so that the logo renders consistently without requiring the font to be installed.

## Identity Assets

- `sposh-logo.svg` — primary horizontal logo in vector format
- `sposh-icon.svg` — standalone SPOSH mark
- `sposh-logo-1000x400.png` — transparent raster version of the horizontal logo
- `sposh-icon-500.png` — transparent raster version of the icon
- `source/` — editable source artwork

SVG should be preferred wherever scalable vector artwork is supported.

## Usage

Please preserve the proportions, geometry, colours, and relative arrangement of the official SPOSH identity.

Do not stretch or distort the artwork, rearrange individual elements, add effects or gradients, or independently recolour parts of the mark.

Adequate clear space should be maintained around the logo so that the open geometry and connected-node structure remain visually distinct.

## Source Files

Editable source artwork is retained in the `source/` directory for maintenance and future development of the SPOSH visual identity.

The public SVG files are intended for general use and distribution.
